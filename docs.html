📦 v2.0.0 🟢 Node.js 18+ ⚛️ React 19 🗄️ MySQL 8 🎨 Tailwind CSS 3 📄 EJS Templates

📋 Ikhtisar Proyek

PT Madinah Computers adalah website company profile untuk toko komputer yang berlokasi di Parung Panjang. Website ini menyediakan informasi layanan (servis laptop, rakit PC, CCTV, dll), katalog software, dan panel admin untuk mengelola konten secara mandiri.


Sistem menggunakan arsitektur hybrid yang menggabungkan:

  • Frontend publik — Single Page Application (SPA) berbasis React.js + Vite untuk pengalaman pengguna yang modern dan responsif
  • Panel admin — Server-side rendered menggunakan EJS (Embedded JavaScript) untuk form CRUD yang simpel dan cepat
  • Backend API — Express.js sebagai pusat logika bisnis, autentikasi, dan komunikasi antara frontend dan database
  • Database — MySQL untuk penyimpanan data konten dan kredensial admin

✅ Prasyarat

🟢 Node.js 18+

Download dari nodejs.org. Pilih versi LTS. Pastikan node -v dan npm -v bisa dijalankan di terminal.

🗄️ MySQL 8+

Install via XAMPP (Windows/Mac) atau apt install mysql-server (Linux). Pastikan service MySQL berjalan di port 3306.

💻 VS Code (Opsional)

IDE yang direkomendasikan. Install extension: ESLint, Prettier, ES7+ React/Redux snippets.

📦 Git

Untuk clone repository. Download dari git-scm.com.

📥 Langkah Instalasi

1. Clone Repository

git clone https://github.com/wahyuwayaw/madinah-computers.git
cd madinah-computers

2. Install Dependencies

npm install

Perintah ini akan menginstall semua dependency untuk frontend (React) dan backend (Express) sekaligus.

3. Setup Database

Pastikan MySQL berjalan, lalu buat database dan import skema:

# Login ke MySQL
mysql -u root -p

# Buat database dan user
CREATE DATABASE madinah_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'madinah_api'@'localhost' IDENTIFIED BY 'Mad1n4hAPI!';
GRANT ALL PRIVILEGES ON madinah_db.* TO 'madinah_api'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Import skema tabel:

mysql -u madinah_api -p'Mad1n4hAPI!' madinah_db < db.sql

4. Konfigurasi Environment (Opsional)

Buat file .env di root proyek jika ingin mengubah konfigurasi default:

DB_HOST=127.0.0.1
DB_USER=madinah_api
DB_PASS=Mad1n4hAPI!
DB_NAME=madinah_db
PORT=3000
SESSION_SECRET=rahasia_anda_di_sini
💡
Jika tidak ada file .env, aplikasi akan menggunakan nilai default yang tertera di atas.

5. Build Frontend

npm run build

Perintah ini akan build React app ke folder dist/. Hanya perlu dijalankan jika ada perubahan pada kode frontend.

🚀 Menjalankan Aplikasi

Mode Development (2 Terminal)

Di mode development, frontend dan backend berjalan terpisah untuk hot-reload:

# Terminal 1: Backend API + Admin
npm run start
# → http://localhost:3000/api
# → http://localhost:3000/admin

# Terminal 2: Frontend Dev Server
npm run dev
# → http://localhost:5173 (Vite dev server dengan HMR)

Mode Production (1 Terminal)

Di mode production, Express serve React build + API + admin sekaligus:

# Build frontend dulu
npm run build

# Jalankan server
npm run start
# → http://localhost:3000 (semua: public + admin + API)

🔌 Dokumentasi API

Semua endpoint API berada di prefix /api dan mengembalikan JSON.


MethodEndpointFungsiBody
GET/api/allAmbil semua settings—
GET/api/data/:keyAmbil satu setting—
POST/api/data/:keyUpdate settingJSON value
POST/api/authLogin admin{username, password}

Contoh penggunaan:

// GET - Ambil data hero
const res = await fetch('/api/data/hero');
const hero = await res.json();
// { heading: "Solusi Laptop...", subtitle: "Jual & Beli..." }

// POST - Update data hero
await fetch('/api/data/hero', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ heading: 'Heading Baru', subtitle: 'Subtitle baru' })
});

// GET - Ambil semua data sekaligus
const res = await fetch('/api/all');
const allData = await res.json();
// { hero: {...}, about: {...}, services: [...], ... }

Valid key values: hero, about, services, software, bidang, core_services, footer

Data Flow:

  1. DataContext memuat semua data dari localStorage saat pertama load
  2. adapter.js (di-inject ke index.html) mencegat localStorage.getItem/setItem
  3. Alih-alih menyimpan di browser, adapter mengirim data ke /api/data/:key (MySQL)
  4. Setiap perubahan dari admin panel langsung ter-refleksi di frontend publik

🗃️ Skema Database

-- Tabel settings: menyimpan konten website sebagai JSON
CREATE TABLE settings (
  `key` VARCHAR(100) PRIMARY KEY,
  value JSON NOT NULL,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- Tabel admin_users: kredensial admin
CREATE TABLE admin_users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  username VARCHAR(50) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

🌐 Deployment

Deploy ke VPS/Server

Upload kode ke server

Clone repo atau upload file ke server. Pastikan Node.js 18+ dan MySQL terinstall.

Install dependencies & build

npm install --omit=dev
npm run build

Setup systemd service (Linux)

# /etc/systemd/system/madinah.service
[Unit]
Description=Madinah Computers Web App
After=network.target mysql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/var/www/madinah
ExecStart=/usr/bin/node server.js
Restart=always
Environment=PORT=3000
Environment=DB_HOST=127.0.0.1
Environment=DB_USER=madinah_api
Environment=DB_PASS=Mad1n4hAPI!
Environment=DB_NAME=madinah_db

[Install]
WantedBy=multi-user.target

Start & enable service

sudo systemctl daemon-reload
sudo systemctl enable madinah
sudo systemctl start madinah

Setup Nginx reverse proxy

# /etc/nginx/sites-available/madinah
location /madinah/ {
    proxy_pass http://127.0.0.1:3000/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

🔧 Troubleshooting

MasalahPenyebabSolusi
ECONNREFUSED saat start MySQL tidak berjalan Jalankan XAMPP MySQL atau sudo systemctl start mysql
Admin login gagal Password hash belum di-generate Jalankan npm run setup atau update hash manual di database
Halaman kosong (blank) Frontend belum di-build Jalankan npm run build
Gambar tidak muncul Asset path salah Pastikan gambar ada di dist/assets/ dan path di database sesuai
Port 3000 sudah dipakai Ada proses lain di port tersebut Ubah PORT di .env atau jalankan PORT=3001 npm start
Admin panel CSS tidak muncul admin.css tidak ter-copy ke dist Pastikan public/admin.css ada dan Express serve /admin/public
